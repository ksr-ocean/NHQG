# Review Files

This directory contains pedagogical reviews for the Dinosaur/NeuralGCM
feasibility spike.

Every Python module, executable script, notebook-like experiment, and
nontrivial test under `dinosaur_spike/` must have a review here. Reviews are
part of the implementation contract and should be updated in the same patch as
the code they explain.

Suggested review sections:

```text
# path/to/file.py

## Responsibility
## Dinosaur / NeuralGCM API Surface
## Numerical Assumptions
## Data Layout, Sharding, And Normalization
## Invariants And Tests
## Known Risks
```
